// SELF-HOSTING

Una community sul tuo server

Il server predefinito è gestito a casa dal proprietario e non ha disponibilità garantita. Un’istanza personale separa account e community; gli utenti di server diversi non si vedono.

Un comando, tre modalità di installazione.

L’avvio guidato chiede versione PocketBase, email e password amministrativa. Può generare una password casuale e salva la configurazione in un file .env privato. Gli installer configurano backend, collezioni, hook e migrazioni.

Su Linux/WSL, con Docker e Compose installati e accesso root/sudo.

bash -c "$(curl -fsSL https://raw.githubusercontent.com/Leonardo-Lalli/FORGE/main/tools/install.sh)" -- docker

Per nuove installazioni. Non usarlo per aggiornare il CT PocketBase già esistente. Dominio HTTPS, reverse proxy e push Firebase richiedono configurazione separata. I nuovi percorsi guidati sono verificati staticamente: la prova completa su Docker/LXC resta necessaria.

Leggi lo script
Preferisci installare manualmente?
  1. 01

    Clona il repository e copia .env.example in .env.

  2. 02

    Scegli una versione PocketBase >= 0.23 e credenziali amministrative uniche.

  3. 03

    Avvia PocketBase, crea il superuser e inizializza le collezioni.

  4. 04

    Applica gli hook e le quattro migrazioni FORGE con backup.

  5. 05

    Configura il reverse proxy HTTPS e mantieni privata l’amministrazione.

  6. 06

    Inserisci l’indirizzo nell’app. Per push social servono Firebase e il worker separato.

Docker è stato configurato per una versione esplicita del binario ufficiale, non latest. Il catalogo salva URL GIF, non i file; le foto e FCM possono usare servizi esterni. Segui la guida completa prima di usare dati reali.
